This is a simple Phonebook Management System developed using PHP and MySQL. The system allows users to store, manage, and search contacts easily.
Features
a)Authentication: User Registration, Login, and Logout.
b)Dashboard: View, edit, and delete your contacts.
c)Add Contact: Easily add new contact names and phone numbers.
d)Search Function: Quickly search for specific contacts.

Project File Structure
This project contains six (6) main files:
i)index.php – Landing page of the system.
ii)register.php – User registration page.
iii)dashboard.php – Main page displaying contacts with edit and delete options.
iv)db.php – Database connection file for MySQL.
v)logout.php – Handles user logout.
vi)style.css – Stylesheet for the system interface.

Setup Guide
Follow these steps to run the system on your computer:
1. Start the Server
Make sure both Apache and MySQL are running through XAMPP 
2. Place the Project Files
Copy the project folder and paste it inside: htdocs (for XAMPP)
2. Create the Database
a. Open your browser and go to phpMyAdmin.
b. Create a new database (e.g., phonebook_db).
c. Import the phonebook.sql file into the newly created database.
d. Configure Database Connection
e. Run the Application
f.Open your browser and enter:
http://localhost/Phonebook-system/
